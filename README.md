# 👗 Cheer Champ — Premium Kids Fashion Store

> A fully responsive e-commerce website for premium kids clothing and fashion.

## 🎯 About
Cheer Champ is a premium kids fashion brand offering exclusive winter and festive collections for children. The website provides a complete online shopping experience with a beautiful and modern UI.

## ✨ Features
- 🛍️ Product catalog with categories
- 🛒 Add to cart functionality
- 👤 User login and signup
- ⭐ Product ratings and reviews
- 🔍 Search functionality
- 📦 Order tracking
- 🚚 Shipping information
- 💳 Checkout page
- 📍 Store locator
- 📱 Fully responsive design

## 🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
Editor: VS Code
Server: Live Server

## 🚀 How To Run
1. Clone the repository
2. Open in VS Code
3. Install Live Server extension
4. Right click index.html
5. Click "Open with Live Server"
6. Website opens at: http://127.0.0.1:5500
